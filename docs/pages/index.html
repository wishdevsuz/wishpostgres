WishPostgres

A fast, lightweight PostgreSQL desktop manager for Linux.

Install anywhere

curl -fsSL https://wishdevsuz.github.io/wish-pgAdmin/install.sh | bash

Detects your distribution, verifies the download against the published checksums and installs the right package. Read the script first if you would rather not pipe it into a shell.

Debian, Ubuntu and derivatives

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://wishdevsuz.github.io/wish-pgAdmin/wishpostgres.gpg \
  | sudo tee /etc/apt/keyrings/wishpostgres.gpg > /dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/wishpostgres.gpg] https://wishdevsuz.github.io/wish-pgAdmin/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/wishpostgres.list > /dev/null
sudo apt update
sudo apt install wishpostgres

Added once, apt upgrade keeps WishPostgres current with the rest of your system.

Fedora, RHEL, openSUSE

curl -fsSL https://wishdevsuz.github.io/wish-pgAdmin/install.sh | bash

The same installer handles rpm distributions. To do it by hand, take the .rpm from the latest release and run sudo dnf install ./wishpostgres-<version>-1.x86_64.rpm.

What you need

glibc 2.35 or newer — Ubuntu 22.04+, Debian 12+, Fedora 36+
WebKitGTK 4.1, installed automatically by the package
PostgreSQL 12 or newer, on the server side
Optional pg_dump and psql, for backup and restore
